# 迭代路线

这份文档记录项目从「看单场 demo 的工具」走向「个人比赛数据档案」的过程：这一轮做了什么、为什么这样做，以及接下来还值得做什么。

## 这一轮之前的状况

界面已经比较完整，但底下有几个结构性问题：

- **统计全靠前端拼。** 数据库里每场比赛的数据是一整段 JSON。首页要做跨场统计，只能逐场请求、在浏览器里合并，库越大越慢。
- **胜负算错了。** 首页用「玩家最后所在的阵营」去对比「CT 方和 T 方各赢了几回合」来判断输赢。但换边之后同一支队伍会在两个阵营下得分，这个比较没有意义，所以首页的胜率和胜负场数都不可信。
- **分阵营做不了。** 原因同上：每个人只有一个整场的阵营标注。
- **demo 不能删。** 统计只能从 demo 重新算，删了就什么都没了；同名文件上传还会覆盖掉另一场的 demo。
- **没有测试。** 原有的测试脚本都要连着本机正在运行的服务和一份真实 demo，换一台电脑就跑不了。

## 这一轮做了什么

**先打地基。** 数据库改成「原始存档 + 规范化事实表」两层：解析出来的原始数据压缩存档，作为长期资产；统计用的表（每人每回合、每人每场、击杀、武器、高光）由程序从存档推出来，跨场统计直接用 SQL 完成。数据库结构有了版本号和自动迁移，旧库升级前会自动备份，旧比赛会在后台自动补算新的统计，不需要原来的 demo。

**把账算对。** 自己逐回合推断每个人站哪边，再把十个人分成两队。队伍比分、个人胜负、CT / T 分开的数据都基于这个结果。合成数据测试覆盖了半场换边、刀局、友军击杀和换边瞬间的脏记录。

**统计搬到后端。** 新增账号汇总、比赛时间线、按阵营 / 地图 / 地图 × 阵营 / 武器 / 经济局面拆分的接口。首页从「N 场就发 N 个请求」变成固定的几个请求。

**分析与 AI。** 规则发现引擎用中位数和 MAD 做基线，找出异常场次、连续下滑、阵营失衡、地图强弱、首杀和残局问题；样本不足的维度一律只提示、不下结论。AI 复盘只接收这些已经算好的数字，可以接各种 OpenAI 兼容接口或 Claude，也可以完全离线。

**高光识别。** 不依赖任何录像工具，纯靠数据识别 ACE、多杀、残局和特殊击杀，并能一键跳到回放的对应时刻。

**demo 生命周期。** 导入时按文件指纹去重；demo 本体可以单独回收，统计不受影响；可以标记「保留回放」；数据库可以一键导出。

**前端重构。** 两千行的单文件按页面拆开（仍然零构建）。顺手修掉了趋势图横轴的拼接错误、对比页按名字对齐玩家（改名就对不上）等问题，并加上了回放的击杀记录、键盘快捷键、热力图按玩家筛选等功能。

**测试。** 合成比赛生成器能按 awpy 的数据格式造出带标准答案的比赛，现在有 74 个自动化测试，包括在无头浏览器里逐页打开界面、确认没有脚本错误。

## 已知的限制

- **还没有在真实 demo 上验证过这一轮的改动。** 开发环境里拿不到真实的 CS2 录像，所有验证都基于严格按 awpy 文档列名构造的合成数据。第一次用真实 demo 跑时，最值得核对的是：自算的 ADR / KAST 与 awpy 给出的是否一致（两者都会存下来，记分板显示的是 awpy 的值），以及队伍比分是否与游戏内一致。
- **bot 不参与统计。** bot 的 steamid 是 0，会被当作无效玩家跳过。
- **中途换人的比赛分队可能不准。** 分队假设每个人整场都在同一支队伍里。
- **助攻口径和 awpy 略有不同。** awpy 会把闪光助攻也算进助攻，自算的分阵营数据只统计击杀记录里的助攻者。
- **加时赛没有专门测试过。** 阵营推断不依赖固定的换边回合，理论上能处理加时，但合成数据目前只覆盖常规 24 回合。
- **任务进度只在内存里。** 程序重启时正在进行的解析会中断（导入记录会保留，重新导入即可）。

## 接下来值得做的事

按价值从高到低大致是：

1. **用真实 demo 做一次回归。** 把一两场真实比赛的解析结果固定成测试样本，校准自算指标和 awpy 的差异，确认分队和比分。这是其他所有工作的前提。
2. **加时赛与非 5v5 模式。** 给合成数据加上加时和两人竞技（wingman），补上测试。
3. **道具分析。** 原始存档里已经有烟、火、闪的完整数据，可以做「每回合道具使用」「闪光效率」「烟雾覆盖」之类的统计，不需要重新解析。
4. **回放只看高光模式。** 把一场里所有高光片段串起来连续播放。
5. **对手 / 队友维度。** 和谁一起排、对上谁的时候表现如何。数据都在 `player_match` 里了，主要是做查询和界面。
6. **视频剪辑。** 高光的 tick 区间已经可以换算成秒。如果用户自己录了屏，可以按区间裁出片段；从 demo 直接出视频需要游戏内录制工具，等确认这类工具对 CS2 可用后再评估。
