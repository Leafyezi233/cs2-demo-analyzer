# tools

开发辅助脚本，不属于程序本体，便携包也不会打包它们。

- `seed_demo_data.py`：用合成比赛造一个数据目录，方便在没有真实 demo 的情况下预览界面。用法见文件开头的说明。
- `windows/`：在 Windows 本机上对便携包做端到端验证的脚本。它们需要真实的 demo 文件和打包好的 `dist/`，路径按原开发机的目录结构写，换机器使用前要先改路径。
- `probes/`：项目早期（M0–M3 阶段）摸索 awpy 数据格式时写的探测脚本和实测记录 `m0_report.txt`。保留下来是因为里面记录了很多「实测得出」的结论，比如回合归属为什么要用 `official_end_tick`。这些脚本引用的是当时的模块路径（例如 `app.metrics`，现在已经移到 `app.analysis.metrics`），不保证还能直接运行。
